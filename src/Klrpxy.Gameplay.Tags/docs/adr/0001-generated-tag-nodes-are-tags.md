# Generated tag nodes are tags

The generated API will expose a tag hierarchy such as `Tags.Unit.Enemy.Boss`, where every generated node is itself an immutable `Tag`. This requires generated node types and a reference-based `Tag` model, but keeps inferred types honest and avoids relying on implicit conversions that behave unexpectedly with `var`, generics, and collection initializers. Each declared tag has one canonical generated instance, equality uses object identity, and generated nodes are exposed through get-only properties with no consumer-accessible constructors. `Tag` exposes `GetPath()` and `GetParent()` while other metadata remains outside its instance API; `Equals`, `GetHashCode`, `GetType`, `ToString`, `GetPath`, and `GetParent` are therefore reserved and cannot be tag path segments.
