# Distribute Gameplay Tags as a Unity package

`Klrpxy.Gameplay.Tags` v0.2.0 is distributed as `Klrpxy.Gameplay.Tags.0.2.0.unitypackage`. Unity imports the generator DLL beneath `Assets`, where its `RoslynAnalyzer` label and disabled runtime platform compatibility are recognized. The package also contains the runtime DLL with ordinary runtime-platform compatibility enabled, plus the import metadata and consumer documentation for both assemblies. A UPM folder package was not selected because it did not load the analyzer in the verified Unity host path. Consumers declare their single Tag Table in the annotated root class; the former external AdditionalFile is rejected with a migration diagnostic. Prototype and compatibility findings remain repository maintenance documents rather than package contents.
